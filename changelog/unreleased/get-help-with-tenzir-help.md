Run `tenzir help` to list all commands, and `tenzir help <command>` for the
flags and examples of one, such as `tenzir help config apply`. This works the
same as `tenzir --help` and `tenzir <command> --help`, except for `run`:
`tenzir help run` describes local and remote runs, and `tenzir run --help` lists
the options of a local run.

The examples in the help now show what you can do with each command, starting
with a typical session in `tenzir help`.
